Category: Add Mesh
---
What is Surface Mesh?
Surface Mesh is a Blender addon for creating and managing surfaces from Bezier curves using the Coons patch method. It is designed for concept car body modeling — quickly sketch panels from 4 boundary curves with live auto-update.

Compatibility
Blender 4.0 and above
Tested on Blender 5.1.0 (Windows)
Tested on Blender 5.1, should work on 5.x (Windows)
Bezier curves only (NURBS not supported)
